# Lab Notebook — nextflow_modules

Chronological log of work sessions on this project, one file per entry. `ls notebook/` lists
them in date order.

Each entry is its own file so that people working on different branches never edit the same
file: two new entries can't produce a merge conflict.

## Rules

- One file per session per person: `YYYY-MM-DD_<short-slug>.md`, e.g.
  `2026-10-22_metapop-module.md`. The slug is a few lowercase hyphenated words naming the main
  topic.
- Never edit, rename or delete someone else's entry. To correct something, write a new entry.
- If you already wrote an entry today, add to it rather than starting a second file.

## Entry format

```markdown
# YYYY-MM-DD
Author: <git user.name>

- What was done / tried
- What happened (concrete results, errors, numbers — not a diff restatement)
- Decision or next step
```
